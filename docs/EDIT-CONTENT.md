# Обновление цен iМастера

## Для мастеров

Откройте [лист «Прайс»](https://docs.google.com/spreadsheets/d/1cUOHTP6BOu53X1YsXvkAN4MZby0kQsa25wBjXgSN6p0/edit?gid=746456487#gid=746456487). В каждой строке одна услуга для одной модели.

- Чтобы поменять стоимость, найдите модель и услугу через фильтр и измените ячейку «Цена, ₽». Введите сумму без знака рубля, например `1500` или `900–1500`.
- Чтобы добавить услугу или устройство, заполните новую строку. Укажите категорию, бренд, модель, услугу и цену. Срок и гарантию можно оставить пустыми. Для нескольких услуг повторите название модели в каждой строке.
- Чтобы временно скрыть услугу, выберите «Нет» в столбце «На сайте». Чтобы снять с сайта устройство, скройте все его услуги. Чтобы убрать позиции из таблицы, удалите соответствующие строки.
- Пустая ячейка «На сайте» равнозначна «Да». Если нужно снять весь каталог с сайта, поставьте «Нет» у всех позиций. Сборка отклоняет полностью пустой лист.

## Как обновляется сайт

Откройте [страницу цен](https://nimble-gaufre-fc7e77.netlify.app/ceny) через несколько минут после правки. Google обновляет опубликованный CSV, а Netlify подставляет актуальные услуги и цены при открытии страницы. Netlify кеширует каталог до двух минут. Повторно развёртывать сайт после правки таблицы не нужно.

В этот лист вносите только данные для публикации. «Нет» скрывает строку в каталоге, а сам CSV доступен для чтения.

URL опубликованного листа задан в `netlify.toml` как `PRICES_CSV_URL`. Сборка создаёт HTML-каталог из Google-прайса, а функция Netlify обновляет этот HTML при запросе. При ошибке в строке прайса или недоступности Google посетители видят каталог из последнего развёртывания. После исправления обновите страницу через несколько минут. Каталог работает и при отключённом JavaScript.

Локальная команда `python3 tools/build.py` использует `prices.csv`, если переменная `PRICES_CSV_URL` не задана. Файлы `site/ceny.html` и `site/data/prices.json` создаются из источника цен при сборке. На хостинге без функции Netlify для обновления нужен новый запуск сборки.

## Акции

Акции редактируются в `promotions.csv`. Порядок строк задаёт порядок слайдов, «Показать» принимает «да» или «нет». Если понадобится управление акциями из отдельного листа Google, опубликуйте его в CSV и задайте `PROMOTIONS_CSV_URL` в настройках сборки.
