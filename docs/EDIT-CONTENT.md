# Обновление без загрузки файлов вручную

## Один раз: подключение
1. Загрузить весь проект в GitHub, включая tools, CSV и netlify.toml. Подключить репозиторий к Netlify. Настройки сборки уже в netlify.toml: команда python3 tools/build.py, папка site.
2. Создать Google-таблицу с двумя листами, импортировав prices.csv и promotions.csv. Названия и порядок столбцов не менять. Для цен использовать текстовый формат ячеек, особенно для значений с / и диапазонов. В таблице должны быть только публичные сведения сайта.
3. Для каждого листа выбрать «Файл → Поделиться → Опубликовать в интернете», формат CSV. Получить две ссылки на CSV.
4. В переменные окружения сборки Netlify добавить PRICES_CSV_URL и PROMOTIONS_CSV_URL с соответствующими ссылками. Ссылки пока не заданы: в этом случае используются CSV из репозитория.
5. Запустить сборку Netlify и проверить демо. Автоматическая публикация изменений кода работает после подключения репозитория; изменения Google-таблицы сами по себе сборку не запускают.

## Обычная работа владельца
Изменить цену, условия акции или «Показать» на «да»/«нет» в Google-таблице. Затем запустить новую сборку в Netlify через Deploys → Trigger deploy. Переносить файлы вручную не нужно. Новую иллюстрацию потребуется один раз загрузить в папку site/images/promotions через GitHub; указать её имя в таблице. Уже загруженные картинки можно свободно переиспользовать.

Для полностью автоматического обновления по расписанию нужен отдельный триггер сборки; он не подключён. Настройку выполнять после получения доступа к выбранному хостингу.

## Поля цен
category: Смартфоны, Планшеты, Ноутбуки или Аксессуары; brand: бренд; model: модель; service: услуга; price: цена; time: срок; warranty: гарантия. Суммы не округлять и не заменять догадками. Пустые срок и гарантия отображаются прочерком. Для изменения перечня моделей достаточно добавить строки.

## Поля акций
Порядок строк задаёт порядок слайдов. «Показать»: да/нет. «Заголовок», «Когда», «Скидка», «Условие» обязательны для включённой акции. «Промокод» и «Картинка» необязательны. «Подпись к промокоду» — инструкция посетителю. «Готовый баннер для ПК» оставлять пустым: изображения с нанесёнными условиями не используются, чтобы текст не расходился между экранами.

Если все акции выключены, блок исчезает. Если одна — кнопок переключения нет. При отключённом JavaScript баннеры отображаются списком. Автопрокрутка выключается при системном уменьшении движения.

## Ошибки
Если Google-таблица недоступна или данные неверны, сборка завершается с ошибкой. Новая версия не должна публиковаться; исправьте таблицу и повторите сборку. Не удаляйте переменные, чтобы незаметно вернуться к старым локальным ценам.

Локальная команда: python3 tools/build.py. Все данные проверяются до записи сгенерированных страниц. Результат — папка site. Запускать tools/update_promotions.py отдельно не требуется.
