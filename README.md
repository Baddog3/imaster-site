# iМастер — текущая сборка

Три страницы: главная, цены, контакты. HTML/CSS/JavaScript. Действующий домен не изменён; публикация не выполнялась.

## Источники данных
- Лист «Прайс» в Google Таблицах — источник цен на [сайте Netlify](https://nimble-gaufre-fc7e77.netlify.app/ceny). `prices.csv` содержит 229 исходных записей для локальной сборки. `site/data/prices.json` и каталог в HTML создаются автоматически: их вручную не редактировать.
- `promotions.csv` — две акции: среда, разъём зарядки, 300 ₽ от 1 500 ₽, РАЗЪЕМ300; четверг, дисплей, 300 ₽ от 3 000 ₽, ДИСПЛЕЙ300.
- Все условия акций теперь выводятся HTML-текстом на компьютере и телефоне. Иллюстрации находятся в `site/images/promotions`. Готовые широкие макеты сохранены как прежние материалы; для текущих слайдов они не используются.
- CSV: UTF-8, разделитель `;`. Google Sheets при экспорте может использовать запятую — сборка поддерживает оба варианта.

## Сборка и просмотр
Из корня проекта: `python3 tools/build.py`. На Windows: `py -3 tools/build.py`.
Затем: `python3 -m http.server 8000 --directory site` и открыть http://localhost:8000.
При запуске в Windows замените python3 на py -3. Если порт занят, используйте 8001 в команде и адресе. Терминал должен оставаться открытым.
Каталог работает и без JavaScript; с JavaScript доступны фильтр и пошаговый выбор. Прямую ссылку на модель можно скопировать из адресной строки. На телефоне услуги отображаются компактными блоками с ценой, сроком и гарантией, без горизонтальной прокрутки.

## Что сохранено
Название, контакты, адрес, часы, исходные суммы, сроки и гарантии, три страницы, основной стиль, иллюстрации, canonical, robots и sitemap. Запись 2500/3000/3000 сохранена с пояснением: точное соответствие моделей и сумм должен подтвердить владелец.

## Что ещё требует подключения
Ссылка на CSV Google Таблиц задана в `netlify.toml`. Как обновлять прайс, описано в `docs/EDIT-CONTENT.md`. Для существующего домена отдельно проверить старые URL и редиректы, контакты, точку карты и актуальность цен. Демо не считать публикацией на действующем домене.
